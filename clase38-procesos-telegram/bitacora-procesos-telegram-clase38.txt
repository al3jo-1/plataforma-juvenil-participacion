1. ¿Qué es un proceso?
Respuesta:
Un proceso es una instancia de un programa que se está ejecutando en el sistema operativo y utilizando recursos como memoria y procesador.

2. ¿Qué significa que un proceso esté corriendo?
Respuesta:
Significa que el programa se encuentra activo y ejecutando instrucciones para realizar una tarea específica.

3. ¿Qué puede pasar si un proceso se detiene?
Respuesta:
La aplicación o servicio asociado puede dejar de funcionar, interrumpiendo las tareas que estaba realizando.

4. ¿Qué comandos usé para observar procesos?
Respuesta:
Comandos como top, ps aux o similares permiten visualizar los procesos que se encuentran ejecutándose en el sistema.

5. ¿Qué es un bot de Telegram?
Respuesta:
Es una aplicación automatizada que interactúa con usuarios de Telegram mediante mensajes y comandos.

6. ¿Qué es un token?
Respuesta:
Es una clave única que permite autenticar y controlar el acceso de una aplicación o bot a un servicio.

7. ¿Por qué el token no debe publicarse?
Respuesta:
Porque cualquier persona que lo obtenga podría controlar el bot o acceder a funciones autorizadas de la aplicación.

8. ¿Dónde se guardó el token?
Respuesta:
El token se almacenó en un archivo .env para mantenerlo separado del código fuente y proteger su acceso.

9. ¿Por qué .env debe estar en .gitignore?
Respuesta:
Porque contiene información sensible que no debe publicarse en repositorios ni compartirse con otras personas.

10. ¿Qué diferencia hay entre telegram-test.js y bot-observacion.js?
Respuesta:
telegram-test.js se utiliza para verificar la conexión y funcionamiento básico del bot, mientras que bot-observacion.js implementa funcionalidades específicas para la observación o gestión de información.

11. ¿Cómo puede servir Telegram a una comunidad digital?
Respuesta:
Puede facilitar la comunicación, enviar notificaciones automáticas, recibir reportes, compartir información y coordinar actividades comunitarias.

12. ¿Qué información no debería enviarse por un bot sin protocolo?
Respuesta:
Contraseñas, tokens, datos personales, información financiera, documentos privados o cualquier información sensible que requiera medidas especiales de protección.
