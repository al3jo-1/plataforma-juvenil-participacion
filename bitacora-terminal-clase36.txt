1. ¿Qué es un sistema operativo?
Respuesta:
Es el software principal que administra los recursos del computador y permite ejecutar aplicaciones y servicios.

2. ¿Qué es el código abierto?
Respuesta:
Es un modelo de desarrollo de software en el que el código fuente puede ser estudiado, modificado y distribuido libremente.

3. ¿Qué significa soberanía tecnológica?
Respuesta:
Es la capacidad de una comunidad, organización o país para controlar y gestionar sus propias tecnologías sin depender completamente de proveedores externos.

4. ¿Qué es Linux?
Respuesta:
Es una familia de sistemas operativos de código abierto basada en el núcleo Linux, utilizada en computadores, servidores y dispositivos electrónicos.

5. ¿Qué es Debian?
Respuesta:
Es una distribución de Linux reconocida por su estabilidad, seguridad y compromiso con el software libre.

6. ¿Qué es un servidor?
Respuesta:
Es un sistema que proporciona servicios, aplicaciones o información a otros equipos o usuarios a través de una red.

7. ¿Qué es una terminal?
Respuesta:
Es una interfaz que permite interactuar con el sistema operativo mediante comandos escritos.

8. Comandos ejecutados y resultado observado:

Comando: whoami
Resultado:
Muestra el usuario actual que está utilizando el sistema.

Comando: hostname
Resultado:
Muestra el nombre asignado al equipo o servidor.

Comando: date
Resultado:
Muestra la fecha y hora actual del sistema.

Comando: pwd
Resultado:
Muestra la ruta completa del directorio actual.

Comando: ls
Resultado:
Lista los archivos y carpetas del directorio actual.

Comando: ls -la
Resultado:
Muestra una lista detallada de archivos, incluyendo archivos ocultos y permisos.

Comando: mkdir practica-linux
Resultado:
Crea una carpeta llamada "practica-linux".

Comando: cd practica-linux
Resultado:
Ingresa al directorio "practica-linux".

Comando: touch notas.txt
Resultado:
Crea un archivo vacío llamado "notas.txt".

Comando: echo "Mi primera practica en terminal Debian" > notas.txt
Resultado:
Escribe el texto indicado dentro del archivo notas.txt.

Comando: cat notas.txt
Resultado:
Muestra el contenido almacenado en notas.txt.

Comando: cp notas.txt copia-notas.txt
Resultado:
Crea una copia del archivo notas.txt.

Comando: mv copia-notas.txt notas-renombradas.txt
Resultado:
Renombra el archivo copia-notas.txt.

Comando: mkdir respaldo
Resultado:
Crea una carpeta llamada "respaldo".

Comando: mv notas-renombradas.txt respaldo/
Resultado:
Mueve el archivo a la carpeta respaldo.

Comando: df -h
Resultado:
Muestra el uso del espacio en disco en formato legible.

Comando: free -h
Resultado:
Muestra la memoria RAM disponible y utilizada.

Comando: uname -a
Resultado:
Muestra información detallada del sistema operativo y del kernel.

Comando: history
Resultado:
Muestra el historial de comandos ejecutados.

Comando: ip a
Resultado:
Muestra la configuración de las interfaces de red y direcciones IP.

Comando: top
Resultado:
Muestra los procesos en ejecución y el uso de recursos del sistema en tiempo real.

9. ¿Qué comando me pareció más útil y por qué?
Respuesta:
El comando "top" porque permite monitorear en tiempo real el uso del procesador, la memoria y los procesos activos.

10. ¿Qué aprendí sobre el uso responsable de la terminal?
Respuesta:
Aprendí que cada comando puede afectar el sistema, por lo que es importante comprender su función antes de ejecutarlo y evitar acciones que puedan comprometer la información.

11. ¿Qué información no debo publicar en capturas o evidencias?
Respuesta:
Contraseñas, direcciones IP sensibles, tokens, claves de acceso, datos personales y configuraciones privadas del servidor.

12. ¿Qué cuidados debo tener al trabajar en un servidor?
Respuesta:
Verificar los comandos antes de ejecutarlos, proteger las credenciales, realizar copias de seguridad y limitar el acceso a usuarios autorizados.

13. ¿Cómo se relaciona la terminal con la soberanía tecnológica?
Respuesta:
La terminal permite administrar directamente sistemas de código abierto, comprender cómo funcionan y tener un mayor control sobre la tecnología utilizada, favoreciendo la independencia tecnológica.
